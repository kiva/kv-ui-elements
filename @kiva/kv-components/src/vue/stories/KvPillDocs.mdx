# KvPill

Pills are compact, read-only status labels. They display a status, category, or metadata about content and are never interactive.

## Component Overview

A pill is a small, read-only label that displays a status, category, or piece of metadata about content. Pills are not interactive and present information the system already knows; users don't click, select, or dismiss them.

## Variations

KvPill supports five variants — `default`, `muted`, `light`, `urgent`, and `caution` — each available in the `default` (34px tall) and `small` (26px tall) sizes.

## Anatomy

<Story of={KvPillStories.Anatomy} />

1. **Leading icon (optional)**: Passed through the `#icon` slot. Size it at 16px (`tw-w-2 tw-h-2`); it inherits the variant's text color.
2. **Pill label**: The default slot content.
3. **Pill container**: Background, padding, and corner radius, set by the `variant` and `size` props.

## Properties

### Pill Label

The label shown inside the pill. The label is the pill's only required content; the leading icon is optional. Because pills are read-only, the label should describe the content.

### Writing Pill Labels

- Short noun or adjective describing state or category — "Funded," "Ending soon," "Agriculture"
- 1–3 words, sentence case, no ending punctuation
- Consistent across the product — if one screen says "Funded," another shouldn't say "Fully funded"

## Accessibility

- Pills are non-interactive: they render as a plain `div`, are not focusable, and expose no click handling
- The label carries the meaning; never rely on the variant color alone to communicate status
- `KvMaterialIcon` is `aria-hidden`, so a leading icon is decorative and the label must stand on its own

## Code Examples

### Default Pill

```vue
<kv-pill>Funded</kv-pill>
```

### Small Pill with a Variant

```vue
<kv-pill variant="urgent" size="small">Ending soon</kv-pill>
```

### Pill with a Leading Icon

```vue
<kv-pill variant="muted">
  <template #icon>
    <kv-material-icon :icon="mdiCheck" class="tw-w-2 tw-h-2" />
  </template>
  Fully funded
</kv-pill>
```
